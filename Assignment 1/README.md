# Short GitHub Exercise

## Purpose

This assignment is a small GitHub collaboration exercise. You will run a short R script, inspect text that came from a website, and make one simple correction before opening a pull request.

You do not need to understand every line of the script before you begin. The goal is to just practice locating the part you need and uncomment a code, which happens in practice. The downloaded file exposes you to command-line examples in GitHub, but you do not need to write or run shell commands for this assignment.

## What the R script does

`inspect_commands.R` uses R to download the official [Git documentation index](https://git-scm.com/docs), reads the result into an object named `scraped_git_commands`, and prints a cleaned table of useful commands and descriptions. 

## Your task

Suppose that we wanted to check if the commands listed in the dataframe `important_commands` exist in the scrapped webpage under the `scraped_git_commands` object (by creating a `TRUE` or `FALSE` status). One command in the table, `git teleport`, is fictional, so it should produce `FALSE`. The code is already there but was accidentally made as a comment.

1. Fork this repository and clone your fork.
2. Go into the `Assignment 1` folder.
3. Run the R script: (You may just open the file directly with Rstudio or use command lines with the following code)

   ```bash
   Rscript inspect_commands.R
   ```

4. Read the output and inspect `scraped_git_commands.txt` and the cleaned command table printed by the R script.
5. You may work on the `main` branch of your forked repository.
6. Make the one small R change marked `TODO` in `inspect_commands.R`: add the `status` column by uncommenting the code below it. 
7. Run the R script again and confirm that the output now includes the new `status` column with both `TRUE` and `FALSE` values.
8. Check your results, it should produce the results that were explained as comments in the R code.
9. Once your result seem correct, commit the R change and push your branch.
10. Open a pull request to the instructor's GitHub page and briefly explain what you changed.

## Files

- `inspect_commands.R` - starter R script that downloads and inspects the command reference
- `important_commands.txt` - a short list of command-line examples to read
- `scraped_git_commands.txt` - generated output; do not edit this file by hand
